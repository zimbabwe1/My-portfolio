## 🚀 Getting Started

1. **Clone or download the repository**
   ```bash
   git clone https://github.com/zimbabwe1/My-portfolio.git
   ```

2. **Open in a browser**
   - Simply open `index.html` in your web browser
   - Or use a live server extension in VS Code

3. **Customize the content**
   - Update your name, bio, and skills in `index.html`
   - Modify colors in `styles.css` (look for CSS variables in `:root`)
   - Add your real social media and GitHub links

## 🎨 Customization

### Update Colors
Edit the CSS variables in `styles.css`:
```css
:root {
  --color-primary: #0066cc;        /* Main blue */
  --color-secondary: #ff6b6b;      /* Accent red */
  --color-dark: #1a1a2e;           /* Dark text */
}
```

### Modify Hero Gradient
Change the gradient in `.hero-section`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```
